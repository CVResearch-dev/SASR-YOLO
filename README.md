# Stage-Aware UAV Small-Object Detection

## Stage-Aware Adaptive Supervision and High-Resolution Feature Refinement for UAV Small-Object Detection

Source preview; training and validation execution are disabled.

To support inspection of the model architecture, we provide:

- `ours_framework/`: CADA, DANeck, CSCM, and ablation source previews.
- `configs/`: model definitions and configuration templates.
- `train.py` and `validate.py`: training and validation entry points.

The experimental hyperparameters are described in the paper.

## Environment Setup

Python 3.10 is recommended. Install the listed dependencies using:

```bash
pip install -r requirements.txt
```
